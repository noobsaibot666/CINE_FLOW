# CineFlow Suite Documentation

CineFlow Suite is a professional desktop application for film and video production crews. It combines pre-production planning, on-set technical discipline, and post-production handoff tools in one local-first workspace.

The docs are organized around the same multi-product documentation pattern used by Darkwave and Creative Director Suite:

- Product direction and release scope
- Technical architecture and data handling
- User guide workflows
- Legal and privacy material
- Development and distribution notes

## Core Workflow

1. Plan the production structure, references, shot list, and camera setup before the shoot.
2. Protect capture quality with look setup, camera matching, on-set checks, and delivery-frame previews.
3. Prep a verified editorial handoff with safe copy, scene organization, contact sheets, review notes, and exports.
