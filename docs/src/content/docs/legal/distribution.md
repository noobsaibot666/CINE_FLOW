# Distribution and Store Notes

CineFlow Suite distribution work should keep privacy, sandboxing, hardened runtime, and platform-specific packaging requirements visible during release readiness.

## macOS

macOS builds should be validated for sandbox behavior, hardened runtime, file access prompts, export permissions, and App Store review requirements.

## Windows

Windows builds should be validated for installer behavior, sidecar binaries, file access, export paths, and Microsoft Store submission requirements where applicable.

## Documentation

Privacy policy, support information, and release notes should be reviewed before each store submission.
