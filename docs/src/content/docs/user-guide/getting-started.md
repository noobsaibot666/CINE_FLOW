# Getting Started

CineFlow Suite is organized into three phases from the top navigation:

| Tab | Purpose |
| --- | --- |
| Pre-Production | Folder structure, references, shot planning, and documentation |
| Production | Project management, look locking, camera matching, and on-set discipline |
| Post-Production | Media review, safe backup, scene organization, and editorial export |

The Utilities button opens focused helper tools without losing your current phase. The command palette, available with `Cmd+K` on macOS or `Ctrl+K` on Windows, gives keyboard-first access to modules and actions.

## Recommended First Project

1. Create the project folder structure before media is recorded.
2. Build a shot list and equipment checklist.
3. Add visual references to the shot planner.
4. Create a production project before camera prep.
5. Lock the look setup and capture guidance.
6. Run camera matching before mixed-camera shoot days.
7. Use safe copy and export reports before editorial handoff.
