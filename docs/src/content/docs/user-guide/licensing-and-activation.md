# Licensing and Activation

CineFlow Suite supports trial and licensed modes. The application is designed to keep core project data local while enforcing product access rules in the desktop shell.

## Trial Mode

Trial mode lets users evaluate the application before activating a license. Trial limitations should be clear in the UI and should not put local media or project metadata at risk.

## Activation

Activation unlocks the licensed product experience. The activation screen and upgrade modal are part of the desktop application, not this documentation site.

## Distribution Notes

Licensing behavior should be validated during release readiness passes for macOS, Windows, and store-distributed builds.
