# Pre-Production

Pre-production is where CineFlow turns a loose plan into a structured shooting package and prepares the media that comes off the cards.

## Safe Copy

Copies media from source cards to your working drives with verification, so every transfer is documented and reviewable. Use it for ingest, backup, and handoff jobs where confidence matters more than speed alone. Safe Copy runs at the start of the workflow, right after the shoot and before editorial.

## Folder Creator

Generates a complete production folder hierarchy in seconds. Use it before recording media so every department knows where camera rolls, audio, proxies, exports, and project files belong.

## Duplicate Finder

Scans selected folders for byte-for-byte identical files and presents reviewable duplicate groups before cleanup. Use it after ingest or during archive passes.

- **Scan options** — set a minimum file size, include or skip hidden files, limit the scan to (or exclude) specific extensions, and skip folders such as `node_modules` or `.git`.
- **Bulk cleanup** — auto-select the copies to remove per group (keep newest, keep oldest, or keep the shortest path), review the selection, then move them all to the Trash in one pass. One copy is always kept in every group.
- **Verified delete** — before anything is trashed, the file being kept and the file being removed are re-checked to confirm they still match.
- **Cancellable** — long scans of large libraries or network drives can be stopped at any time, and progress shows how much has been read.

## Shot List

Builds scene and shot rows, equipment checklists, and polished day-sheet PDFs. Use it during production meetings, tech scouts, and shoot mornings.

## Reference Board

Loads clips or images, tags each reference by shot size and camera movement, and sequences references in canonical, hook-first, or manual order. Vertical 9:16 mode includes safe-frame overlays for social delivery.

From the same board you can export reference sheets as a PDF or image, or a **grid mosaic** — a multi-frame contact wall — with control over frames per clip, sequential or shuffled order, and square or original cell shape. Use it for visual reports, coverage documentation, client deliverables, and BTS summaries.
